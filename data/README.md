# Put the data pack here

This folder is intentionally empty in the repository. The data pack is not committed.

Copy these four files from `corvane_data_pack` into this folder:

```
data/brands.json
data/facts.json
data/prompts.csv
data/responses.jsonl
```

Any later weekly files (`.xlsx`, `.csv`, `.jsonl` or `.json`) can be dropped here too, or uploaded on the app's *Data & exports* page. Everything in this folder except this README is git-ignored.
